One pickup line from a vending machine to a passing human, written for make.fun's "One Line, One Minute: The Vending Machine Pickup Line Contest". A deterministic Python program (standard library only) writes the single chosen line to `entry.txt`.

## Run it

```sh
python3 main.py
```

By default the program writes to the directory named by `MAKEFUN_OUTPUT_DIR` (or `/output` when that variable is unset). Pass an output directory as the first argument to override it:

```sh
python3 main.py ./output
```
